# FintechX Landing Page (React + Vite + Tailwind)

A high-fidelity React recreation of the **FintechX** Framer template — a modern finance & fintech SaaS landing page.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS v4

## Sections included

- Sticky navbar
- Hero with AI badge + dashboard mockup
- Social proof / trusted by
- Before / After challenges
- Core features grid
- How it works
- Use cases
- Platform stats
- Testimonials
- Pricing (monthly / yearly toggle)
- FAQ accordion
- Final CTA
- Footer

## Notes

This is a clean recreation of the public FintechX Framer template structure and visual language.  
Replace copy, colors, and images as needed for your brand.
